# Манифест: справочник полей

Манифест — файл `manifest/host.json`. Это JSON с комментариями: всё после `#`
до конца строки игнорируется, висячие запятые допускаются.

**Главное правило: нет ключа — ничего не происходит.** Пустой манифест `{}`
означает «не делай с хостом ничего», и keel так и поступит.

Создать свой:

```bash
cp manifest/host.example.json manifest/host.json
keel validate            # проверить, что нет опечаток
```

## Разделы

| Раздел | Появится | Назначение |
|--------|----------|------------|
| `host` | Фаза 0–1 | настройки самого хоста |
| `storages` | Фаза 1 | хранилища |
| `guests` | Фаза 2 | виртуальные машины и контейнеры |
| `backup` | Фаза 1 | расписание резервного копирования |

Любой другой раздел — ошибка, и `keel validate` об этом скажет. Это защита от
опечаток вроде `hosts` вместо `host`.

## host

### host.repos

Какой репозиторий Proxmox использовать.

| Значение | Что это |
|----------|---------|
| `no-subscription` | бесплатный, для домашнего сервера |
| `enterprise` | платный, нужна действующая подписка |
| `test` | тестовый, не для рабочих машин |

Выбранный репозиторий включается, остальные **выключаются, но не удаляются**:
в новом формате (`*.sources`) добавляется `Enabled: false`, в старом
(`*.list`) строки комментируются. Вернуть обратно — одна правка.

Платный ceph-репозиторий тоже выключается, если выбран не `enterprise`: без
подписки он отвечает 401 и ломает `apt update`.

Нет ключа — репозитории не трогаются вообще.

## guests

Появится в Фазе 2. Планируемый вид:

```jsonc
"guests": [
  {
    "id": 100,               # обязательное, от 100
    "name": "haos",          # имя гостя
    "profile": "haos",       # рецепт из profiles/
    "cores": 2,
    "memory": 4096,          # МБ
    "disk": "32G",
    "storage": "local-lvm",
    "bridge": "vmbr0",
    "start_on_boot": true
  },
  {
    "id": 101,
    "name": "desktop",
    "profile": "desktop",
    "graphics": "dri",       # dri (LXC) | virgl (ВМ) | passthrough
    "packages": ["firefox", "vlc", "pipewire"]
  }
]
```

Поле `graphics` решает, что именно будет создано: `dri` — контейнер LXC с
доступом к видеокарте хоста, `virgl` — виртуальная машина с 3D-ускорением без
проброса. Сравнение вариантов — в [docs/PLAN.md](PLAN.md).

Уже существующий гость с таким `id` **не перезаписывается**: keel сообщит о
расхождении и оставит его в покое.

## Чего в манифесте нет намеренно

Пароли и приватные ключи. В манифесте могут быть только пути к файлам, которые
лежат вне репозитория. `manifest/host.json` по умолчанию в `.gitignore`.
