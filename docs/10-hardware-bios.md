# Железо и BIOS

То, что скриптом не сделать: до этих настроек добирается только человек с
монитором и клавиатурой. Держи страницу под рукой при сборке нового хоста.

## Что включить в BIOS

| Настройка | Зачем | Как обычно называется |
|---|---|---|
| Аппаратная виртуализация | без неё не будет ВМ вообще | `SVM Mode` (AMD), `Intel VT-x` |
| IOMMU | нужен только для проброса устройств | `IOMMU`, `AMD-Vi`, `Intel VT-d` |
| Above 4G Decoding | проброс видеокарт | `Above 4G Decoding`, `Resizable BAR` |
| Автовключение после сбоя питания | хост поднимется сам | `Restore on AC Power Loss` → `Power On` |

Аппаратная виртуализация включена почти везде по умолчанию. IOMMU —
почти нигде.

Проверить после установки, не перезагружаясь в BIOS:

```bash
keel doctor          # раздел «Графика» покажет состояние IOMMU
grep -c -E 'svm|vmx' /proc/cpuinfo    # 0 означает, что виртуализация выключена
```

## Диски

Proxmox по умолчанию отдаёт под систему весь выбранный диск. Если планируешь
держать данные на том же диске — задай размер в установщике (Options →
`hdsize`), иначе под систему уйдёт всё.

ZFS требует памяти: считай примерно 1 ГБ на каждый терабайт хранилища сверх
того, что нужно гостям.

**Записывай, что где стояло.** После аварии «какой из четырёх дисков был
системным» — неожиданно трудный вопрос. Эту информацию keel сохраняет в
`host-report.txt` внутри архива конфигурации, но только если архив есть.

## Питание и охлаждение

Мини-ПК на APU (например, Ryzen 8745HS) под нагрузкой греются, а в закрытой
тумбе — сильнее, чем кажется. Проверить температуру:

```bash
apt install -y lm-sensors && sensors
```

Устойчиво выше 85 °C — пора думать о продуве.

## Проброс устройств

Проброс видеокарты припаркован осознанно —
см. [BACKLOG.md](BACKLOG.md) и [30-desktop.md](30-desktop.md). Если всё же
соберёшься, из BIOS понадобятся IOMMU и Above 4G Decoding, а дальше — разбор
IOMMU-групп, который `keel doctor` уже показывает.
